# Francisco Aristi Reina — Academic Research Website

A minimal, responsive, static research website. No build step or framework required.

## Preview
Open `docs/index.html` in a browser. The Google Fonts stylesheet requires an internet connection; fallback fonts work offline.

## Publish using GitHub Pages
The site lives in `docs/` and is served by GitHub Pages from **`main` / `/docs`** (Settings → Pages → Deploy from a branch).

Address: https://ferdos202150762.github.io/

The repository must be public (on a free GitHub plan) for Pages to serve it. For a custom domain, configure it in Settings → Pages and set the DNS records with your registrar.
